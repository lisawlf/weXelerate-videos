# Brand layer: Future Forward

Use only when the video is about the Future Forward conference (tickets, speakers, expo,
pitching arena, recap). Source of truth for graphics:
[FF26 Design System](https://github.com/lisawlf/ff26-design-system). Load the `ff-copy`
skill before writing any FF copy.

## Event facts (verify the current year before use)

- Future Forward 2026 · Thursday 26 November 2026 · **weXelerate Innovation Hub**,
  Praterstraße 1, 1020 Vienna.
- Never mention "Design Tower" or Jean Nouvel.
- Tickets / info: futureforward.at · Hashtags `#FutureForward2026 #FF26`.
- Pricing changes over time: never put a price or deadline on screen unless the request
  confirms it is current.

## Palette

| Token | Hex | In video |
|---|---|---|
| Acid | `#dcff00` | **One element per frame**: the CTA pill or the URL pill. Black text only |
| Ink | `#0e0e0e` | Dark canvas |
| Night navy gradient | `#11264f → #0a1834 → #050b1a → #000` (radial from bottom right) | End card background |
| White | `#ffffff` | Type on footage |

## Type

Sora **800** for hook, names and end card, tracking -0.045em; uppercase is allowed for
big statements ("BORING CORPORATE EVENT?"). JetBrains Mono uppercase for chips, dates,
venue. Barlow for body.

## Shapes

Every box (chip, plate, card) has an **8 px** corner radius: `rgba(0,0,0,.5)` fill, 1 px
`rgba(255,255,255,.5)` hairline. Pills stay 50 px.

## Logo (`assets/logos/future-forward/`)

| File | Use |
|---|---|
| `ff-logo-white.png` | Default in video: top-left header (58 px tall) and end card (100 px tall) |
| `ff-logo-black.png` | Light backgrounds only |
| `ff-mark-white.png` / `ff-mark-black.png` | Chevrons alone, small spots |

Never recolour, stretch, box, rotate or mirror the chevrons. When the host should be
named, use the lockup "the yearly flagship event by" + weXelerate white wordmark, small.

## Copy

- No em dashes. No parallel triads ("Connect. Learn. Act."). No exclamation marks.
- **Never** "This is not a conference for spectators" or any "... for spectators" variant.
- "the room", "Navigate the Unknown", "curated", "decision-makers" are on brand.
- Emoji: sparing, captions only, never on screen.

## End card (default)

Night navy gradient, FF logo, Sora 800 headline (e.g. "See you in the room."), mono meta
`26.11.2026 · weXelerate Innovation Hub · Vienna`, acid CTA pill
(`Get your ticket  FUTUREFORWARD.AT`).

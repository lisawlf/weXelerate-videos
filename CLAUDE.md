# weXelerate videos

For any video request (a GitHub issue labelled `video-request`, or "make a reel / recap /
interview cut"), follow `skills/wexelerate-video/SKILL.md` step by step and read the
reference files it names before the step that needs them.

- Video projects, footage, renders and voiceover files live next to the footage on
  OneDrive, never in this repo (it is public).
- When the user corrects a name, a pronunciation, a fact or a rule, update the matching
  file in `skills/wexelerate-video/references/` in a pull request.
- No em dashes in any copy. weXelerate copy has no emoji.
